ตัวเลือก

สองช่องล่างและ hysteresis ใช้กับทุกวิธียกเว้น blackhat ซึ่งต้องคงไว้ให้ตรงชุดเทรน

R จากโมเดล R จาก anchor landmark อื่น กรอบจังหวะ

ระยะทั้งหมดวัดจากเส้นกริดหลักของภาพ (เส้นละ 5 mm) โดยใช้เส้นที่อยู่นอกจังหวะซ้ายสุดเป็น x = 0

กากบาทเขียว = ตำแหน่งที่ชุดเทรนวางยอด R ไว้ ครอปเหล่านี้ควรหน้าตาเหมือนภาพชุดเทรนโมเดลจุด

binarization ที่ป้อนโมเดลครอป (ก่อนตีกรอบ)

นี่คือภาพที่โมเดลครอปเห็นจริง ปรับค่าในแถบ "ตัวเลือก" แล้วภาพนี้เปลี่ยนทันที โดยไม่ต้องรันตรวจจับใหม่ ดูสองอย่าง: ปลายยอด R ยังอยู่ครบไหม และกริดเหลือมากจนกลบเส้นหรือเปล่า

preprocessing ที่ป้อนโมเดลจุด (หลังตัดครอป)

ครอปจริงที่ส่งเข้าโมเดลจุด ผ่าน preprocessing ของโมเดลจุด ในแถบตัวเลือกแล้ว กากบาทเขียว = ตำแหน่งที่ชุดเทรนวางยอด R ไว้ (ราว 10% จากขอบบน) ครอปพวกนี้ควรหน้าตา เหมือนภาพชุดเทรนโมเดลจุด

ink mask ของจังหวะเดียว (ใช้หายอด R ด้วย image processing)

ซ้าย = ภาพจริงของจังหวะ ขวา = ink mask ที่ใช้หายอด R ถ้ามีแถบตั้งพาดเต็มความสูงแปลว่าเส้นกริดหลุดเข้ามา
anchor จาก image processing R จากโมเดล R ที่ใช้ค่าจาก anchor landmark อื่น
