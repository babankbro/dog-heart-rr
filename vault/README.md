# EKG R-Peak Knowledge Vault

This vault documents the methodology, architecture, implementation, validation, and operation of the EKG R-peak project. Open this folder directly as an Obsidian vault, or read the Markdown files in any editor.

Start at [[00 - Project Map]].

## Documentation rules

- Describe the code as it currently behaves, not only as intended.
- Keep configuration values in [[08 - Configuration and Decisions]] synchronized with `ekg_rpeak/config.py`.
- Record experimental conclusions with the dataset size, metric, and configuration used.
- Link architectural claims to the responsible module.
- Treat images under `data/` and patient metadata as sensitive clinical data.
